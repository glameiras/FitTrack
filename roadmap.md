# FitTrack roadmap

- [x] Autenticação por e-mail e Google, recuperação de senha e perfis privados
- [x] Banco de dados com proteção por usuário e armazenamento privado de fotos
- [x] Home mobile-first com resumo, IMC, metas e navegação inferior
- [x] Treinos, exercícios, conclusão diária e histórico persistente
- [x] Dieta, refeições, alimentos e progresso diário
- [x] Evolução com peso, cargas, cardio, gráficos e fotos comparativas
- [x] Perfil editável, cálculo de IMC e meta de peso
- [x] Validação de segurança e verificação visual mobile
